# 服务稳定性问题分析与解决 · 2026-04-16 09:22

## 问题现象
后端和前端服务启动后不久就会自动断开/退出。

## 根本原因
OpenClaw 的后台进程管理机制会终止通过 `background: true` 启动的进程。

**历史记录**（MEMORY.md 2026-04-15）：
> 修复服务启动问题 - OpenClaw后台进程会终止background进程，改用Start-Process启动独立进程

## 解决方案
使用 Windows 的 `start` 命令启动独立命令行窗口，不受 OpenClaw 进程管理影响。

## 创建的脚本

| 文件 | 用途 |
|------|------|
| `start-all.bat` | 一键启动前后端服务 |
| `stop-all.bat` | 一键停止所有服务 |

## 使用方法

### 启动服务
双击运行 `start-all.bat`，会自动：
1. 检查并清理端口占用
2. 启动后端（端口 3001）
3. 启动前端（端口 5173）
4. 打开浏览器

### 停止服务
双击运行 `stop-all.bat`

## 技术细节
- 使用 `start "窗口标题" cmd /c "命令"` 启动独立窗口
- 窗口标题用于后续停止时精确定位
- 服务运行在独立窗口中，关闭窗口即停止服务
